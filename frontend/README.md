# Lightweight Frontend

A simple and lightweight frontend for the lightweight backend application.

## Setup

1. Start the backend server first (see backend README)

2. Install dependencies:
```bash
npm install
```

3. Start the frontend:
```bash
npm run dev
# or
npm start
```

4. Open your browser and navigate to:
```
http://localhost:8081
```

## Features

- User registration and login
- Product browsing
- Product creation (requires login)
- User profile viewing
- Responsive design
- Simple, clean interface

## Usage

1. Register a new account or login
2. Browse products on the Products page
3. Add new products (requires login)
4. View your profile information

## Browser Compatibility

Works on all modern browsers including Chrome, Firefox, Safari, and Edge.
